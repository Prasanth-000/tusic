## 1. UNIT TESTS (`cargo test`)

### 1.1 `db.rs` — Playlist Round-Trip

**Problem:** `open()` hardcodes the DB path.  
**Cleanest fix:** Add an env-var override in `open()`:

```rust
// In db.rs, inside open():
let path = std::env::var("KALKI_DB_PATH")
    .unwrap_or_else(|_| DEFAULT_DB_PATH.to_string());
```

**Test module:**

```rust
#[cfg(test)]
mod tests {
    use super::*;
    use std::fs;

    fn temp_db() -> (String, Db) {
        let path = format!("/tmp/kalki_test_{}.db", std::process::id());
        std::env::set_var("KALKI_DB_PATH", &path);
        let db = Db::open().unwrap();
        (path, db)
    }

    #[test]
    fn playlist_round_trip() {
        let (path, mut db) = temp_db();
        db.add_playlist("Test".into(), vec!["a.mp3".into(), "b.mp3".into()]);
        db.save().unwrap();

        let db2 = Db::open().unwrap();
        let pl = db2.get_playlist("Test").unwrap();
        assert_eq!(pl.tracks, vec!["a.mp3", "b.mp3"]);

        db2.delete_playlist("Test").unwrap();
        db2.save().unwrap();
        let db3 = Db::open().unwrap();
        assert!(db3.get_playlist("Test").is_none());

        fs::remove_file(&path).ok();
    }

    #[test]
    fn add_delete_track() {
        let (path, mut db) = temp_db();
        db.add_playlist("P".into(), vec![]);
        db.add_track("P", "x.mp3").unwrap();
        db.add_track("P", "y.mp3").unwrap();
        db.delete_track("P", "x.mp3").unwrap();
        let pl = db.get_playlist("P").unwrap();
        assert_eq!(pl.tracks, vec!["y.mp3"]);
        fs::remove_file(&path).ok();
    }
}
```

### 1.2 `app.rs` — Track-Ended Grace Logic

**Refactor:** Extract the decision into a pure function:

```rust
// Exact signature — place in app.rs (or a new `logic.rs`):
pub fn should_treat_as_ended(
    was_playing: bool,
    now_playing: bool,
    has_current: bool,
    dur: f64,
    switching: bool,
) -> bool {
    if !was_playing || now_playing || !has_current {
        return false;
    }
    if switching {
        return false; // user-initiated switch — don't fire "ended"
    }
    dur > 0.0
}
```

**Test vectors (including the bug it fixes):**

```rust
#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn ended_detection() {
        // The bug: switching=T was treated as ended → "queue ended" on manual switch
        assert!(!should_treat_as_ended(true, false, true, 180.0, true)); // switching → false
        assert!(should_treat_as_ended(true, false, true, 180.0, false)); // real end → true

        // Edge cases
        assert!(!should_treat_as_ended(false, false, true, 180.0, false)); // wasn't playing
        assert!(!should_treat_as_ended(true, true, true, 180.0, false));   // still playing
        assert!(!should_treat_as_ended(true, false, false, 180.0, false)); // no current track
        assert!(!should_treat_as_ended(true, false, true, 0.0, false));    // zero duration (stream)
    }
}
```

### 1.3 `music_visual.rs` — Render Determinism & Bounds

```rust
#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn render_is_deterministic() {
        let (w, h, t) = (80, 10, 1.5);
        let a = render(w, h, t);
        let b = render(w, h, t);
        assert_eq!(a, b);
    }

    #[test]
    fn render_no_panic_at_extremes() {
        for w in 1..=120 {
            for h in 1..=16 {
                let _ = render(w, h, 0.0);
                let _ = render(w, h, 10.0);
            }
        }
    }

    #[test]
    fn strand_continuity() {
        let (w, h) = (80, 10);
        let out = render(w, h, 2.0);
        for col in 0..w {
            let has_glyph = (0..h).any(|row| out[row][col] != ');
            assert!(has_glyph, "column {} empty", col);
        }
        // Adjacent columns: at least one row where both have glyphs
        for col in 0..w-1 {
            let connected = (0..h).any(|row| {
                out[row][col] != ' && out[row][col+1] != '
            });
            assert!(connected, "gap between columns {} and {}", col, col+1);
        }
    }
}
```

### 2.1 `--selftest-units` — Pure-Fn Assertions Without `cargo test`

```rust
fn selftest_units() -> bool {
    let mut ok = true;

    // should_treat_as_ended
    ok &= !should_treat_as_ended(true, false, true, 180.0, true);
    ok &= should_treat_as_ended(true, false, true, 180.0, false);
    ok &= !should_treat_as_ended(false, false, true, 180.0, false);

    // keyword_of
    ok &= keyword_of("Manohari (Official Video)") == "Manohari";

    // render determinism
    ok &= render(80, 10, 1.5) == render(80, 10, 1.5);

    // render bounds
    for w in 1..=120 {
        for h in 1..=16 {
            let _ = render(w, h, 0.0);
        }
    }

    println!("selftest-units: {}", if ok { "PASS" } else { "FAIL" });
    ok
}
```

### 2.2 History Back-Stack Simulation

**Problem:** `Engine` is a concrete struct — can't mock.  
**Minimal refactor:** Add a trait for the engine surface used by `play_track`/`back_track`:

```rust
// In app.rs or engine.rs:
pub trait EngineLike {
    fn play(&mut self, path: &str) -> Result<(), String>;
    fn stop(&mut self);
    fn is_playing(&self) -> bool;
}

impl EngineLike for Engine { /* delegate to existing methods */ }
```

Then `App` holds `Box<dyn EngineLike>` instead of `Engine`.

**Selftest:**

```rust
struct FakeEngine {
    current: Option<String>,
    fail_next: bool,
}

impl EngineLike for FakeEngine {
    fn play(&mut self, path: &str) -> Result<(), String> {
        if self.fail_next {
            self.fail_next = false;
            return Err("simulated failure".into());
        }
        self.current = Some(path.to_string());
        Ok())
    }
    fn stop(&mut self) { self.current = None; }
    fn is_playing(&self) -> bool { self.current.is_some() }
}

fn selftest_history() -> bool {
    let mut eng = FakeEngine { current: None, fail_next: false };
    let mut app = App::new(Box::new(eng));

    app.play_track("A.mp3").unwrap();
    app.play_track("B.mp3").unwrap();
    app.play_track("C.mp3").unwrap();

    app.back_track().unwrap();
    assert_eq!(app.current_track(), Some("B.mp3"));
    app.back_track().unwrap();
    assert_eq!(app.current_track(), Some("A.mp3"));

    // Suppress flag doesn't stick after failure
    app.engine.fail_next = true;
    app.play_track("D.mp3").unwrap_err();
    app.back_track().unwrap(); // should still work
    assert_eq!(app.current_track(), Some("A.mp3"));

    println!("selftest-history: PASS");
    true
}
```

## 3. DEBUGGING PLAN — 5 Common Failure Modes

### 3.1 "Queue ended" on Track Switch

| Item | Detail |
|---|---|
| **Symptom** | Manual track switch shows "Queue ended" / stops playback |
| **Repro** | Play A → play B (manual) → observe "ended" fired |
| **Root cause** | `should_treat_as_ended` returned `true` when `switching=true` |
| **Proof** | `--selftest-units` fails on `should_treat_as_ended(true,false,true,180.0,true) == false` |
| **Regression test** | The unit test in §1.2 — keep it permanent |

---

### 3.2 MPRIS EmptyArray Panic

| Item | Detail |
|---|---|
| **Symptom** | Panic: `EmptyArray` from `zbus`/`mpris` when metadata has no track |
| **Repro** | Start app with empty playlist → MPRIS service tries to publish metadata |
| **Root cause** | `Metadata` builder called with `None` track ID → `EmptyArray` error |
| **Proof** | Run with `RUST_BACKTRACE=1`; stack shows `mpris::Metadata::builder()` |
| **Fix check** | Guard: `if let Some(track) = current { ... } else { skip publish }` |

---

### 3.3 Blank DNA Panel

| Item | Detail |
|---|---|
| **Symptom** | Visualizer area renders empty (no glyphs) |
| **Repro** | Play any track → switch to DNA view → blank |
| **Root cause** | `render()` returns all spaces — either `w`/`h` are 0, or audio data buffer is empty |
| **Proof** | Add debug print in `render()`: `eprintln!("w={} h={} t={}", w, h, t)`; check `--selftest-viz` output |
| **Fix check** | `--selftest-viz` should show non-empty output; unit test `strand_continuity` catches empty columns |

---

### 3.4 Search Returns Nothing

| Item | Detail |
|---|---|
| **Symptom** | Typing in search box yields zero results even for existing tracks |
| **Repro** | Search "Manohari" → empty; but track exists in library |
| **Root cause** | `keyword_of` fails to strip `(Official Video)` → search term mismatch; or DB query uses exact match instead of `LIKE` |
| **Proof** | `--selftest-units` fails on `keyword_of("Manohari (Official Video)") == "Manohari"` |
| **Fix check** | Unit test in §1.4; also check DB query uses `%term%` |

---

### 3.5 Stuck Loading Bar (Searching Flag Never Cleared)

| Item | Detail |
|---|---|
| **Symptom** | Loading bar spins forever after search; UI frozen |
| **Repro** | Type search → press Enter → bar appears → never clears |
| **Root cause** | `searching` flag set to `true` before async search, but the completion callback never runs (error path missing `searching = false`) |
| **Proof** | Add `eprintln!("searching={}", searching)` in the UI tick; check `--selftest-app` for flag state |
| **Fix check** | Ensure all exit paths from search set `searching = false` — including error/empty results |
